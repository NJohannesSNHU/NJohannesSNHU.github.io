# Computer Science Capstone Project

## Android Inventory Management Application

**Original Course:** CS 360 – Mobile Architecture and Programming

The Android Inventory Management Application was originally developed as part of my coursework at Southern New Hampshire University.

The application provides inventory management functionality through an Android interface. It allows users to manage inventory information and interact with stored data.

For my CS 499 capstone, I will enhance this application across three areas of computer science.

---

## Software Engineering and Design

### Planned Enhancements

I plan to improve the overall structure and organization of the application.

Potential improvements include:

- Improving code organization and maintainability.
